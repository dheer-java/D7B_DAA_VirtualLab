# Design and Analysis of Algorithms Virtual Lab D7B

## Overview
This repository contains a collection of algorithm visualizers and virtual labs developed as part of our coursework for the "Design and Analysis of Algorithms" subject. The projects were created by students to demonstrate the working principles and implementation of various core computer science algorithms.

## Algorithms Covered
The repository includes implementations and visual simulations for the following algorithms:
* **String Matching**
* **N-Queen Problem** (Backtracking)
* **Dijkstra's Algorithm** (Single-Source Shortest Path)
* **Graph Coloring**
*  **Kruskal's Algorithm** (Minimum Spanning Tree)
* **Longest Common Subsequence (LCS)** (Dynamic Programming)
* **Dragon Problem** (Minimum Cost Path using Dynamic Programming)
* **Selection Sort**

## Repository Structure
Each folder in this repository represents an individual or group project. The directories are named to indicate the algorithm implemented, along with the respective student's name and roll number (e.g., `[Algorithm]_[RollNo]_[Name]`). 

## How to Run
Since these are independent projects developed by different students, the exact technology stack and execution steps might vary. 
1. Navigate into the specific project directory you want to run.
2. Look for the main entry file (typically an `index.html` file for web-based visualizers or a main script file).
3. Follow any specific instructions provided within that individual folder.
